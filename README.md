# 🚀 Space Shooter com Python + Pygame

Projeto simples e didático de um jogo estilo **Space Shooter**, desenvolvido para demonstração em sala de aula.

## 🎯 Objetivos de aprendizagem

O projeto permite trabalhar conceitos básicos de programação:

- variáveis;
- condicionais `if`;
- laço `while`;
- eventos do teclado;
- coordenadas X e Y;
- números aleatórios;
- colisões;
- pontuação;
- biblioteca Pygame.

## 🎮 Como jogar

- **←** move a nave para a esquerda.
- **→** move a nave para a direita.
- **Espaço** dispara.

Acerte o inimigo para aumentar sua pontuação.

## 🛠️ Requisitos

- Python 3
- Pygame

## 📦 Instalação

Clone o projeto e entre na pasta:

```bash
git clone https://github.com/FranciscoDias87/space-shooter-pygame.git
cd space-shooter-pygame
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python space_shooter.py
```

## 🧑‍🏫 Sugestão para a aula

Uma sequência simples é:

1. Criar a janela do jogo.
2. Desenhar a nave.
3. Movimentar a nave.
4. Criar o inimigo.
5. Implementar o tiro.
6. Detectar colisões.
7. Adicionar a pontuação.

Assim, os alunos acompanham a construção do jogo passo a passo.
