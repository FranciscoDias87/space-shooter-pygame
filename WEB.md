# Versão Web

A pasta raiz também contém uma versão web do Space Shooter, criada em HTML, CSS e JavaScript puro.

Arquivos:

- `index.html` — estrutura da página e do jogo.
- `style.css` — visual e responsividade.
- `game.js` — lógica do jogo.

## Rodar localmente

Você pode abrir o `index.html` diretamente no navegador ou usar uma extensão como Live Server no VS Code.

## Publicar na Vercel

1. Entre em https://vercel.com
2. Clique em **Add New > Project**
3. Importe o repositório `FranciscoDias87/space-shooter-pygame`
4. Em **Framework Preset**, escolha **Other**
5. Não informe comando de build
6. Mantenha o diretório raiz como `./`
7. Clique em **Deploy**

Como é um projeto estático, a Vercel publicará o `index.html` diretamente.

## Controles

- Esquerda: seta esquerda ou A
- Direita: seta direita ou D
- Atirar: barra de espaço
- Pausar: P
- Iniciar: Enter
